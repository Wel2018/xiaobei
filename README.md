# xiaobei 医院巡检机器人系统

## 📖 项目简介

xiaobei 是一个智能化的医院巡检机器人系统，专为现代医疗机构设计，能够自主执行病房巡检、患者监护、生命体征采集等任务。该系统集成了先进的机器人技术、计算机视觉、传感器融合和人工智能算法，为医护人员提供高效、准确的辅助服务。

## 🏗️ 系统架构

### 整体架构
```
xiaobei/                      # 护士站巡检控制系统
├── xiaobei-backend/          # 后端服务 (底盘、机械臂、导航、巡检、患者管理、生命体征、报警集成)
├── xiaobei-frontend/         # 前端界面 (实时监控、地图、设备监控、巡检管理、系统配置)
├── xiaobei-ext/              # 扩展服务 (摄像头、跌倒检测等)
├── xiaobei-arm/              # 机械臂控制服务
├── xiaobei-face/             # 面部表情动画播放器
└── xiaobei-data/             # 数据存储 (图像采集、地图数据、数据库、系统配置文件等)
```

### 核心组件

| 组件             | 组件名           | 技术栈                        | 主要功能                                                     |
| ---------------- | ---------------- | ----------------------------- | ------------------------------------------------------------ |
| **后端服务**     | xiaobei-backend  | FastAPI, Python, SQLite       | 底盘控制、机械臂管理、地图导航、巡检任务、患者信息、生命体征数据、报警记录、传感器集成 |
| **前端界面**     | xiaobei-frontend | Vue.js, TypeScript, Vite      | 实时监控面板、地图可视化、设备状态监控、巡检任务管理、患者信息展示、报警记录查看、系统设置 |
| **设备服务**     | xiaobei-ext      | FastAPI, OpenCV, pyrealsense2 | RealSense D455 深度相机、USB 相机管理、视频流传输 (WebSocket)、跌倒检测、输液监测服务集成、消毒灯控制 |
| **机械臂服务**   | xiaobei-arm      | ROS, Socket                   | 睿感机械臂 ROS 驱动和 Socket 通信中间件                      |
| **面部表情服务** | xiaobei-face     | PySide6, python-vlc           | 机器人面部表情动画播放                                       |

## 🚀 核心功能

### 1. 智能巡检
- **自动路径规划**: 基于预设地图和导航点位的自主导航
- **多床位巡检**: 支持按病房、床位分组进行巡检
- **定时巡检**: 可配置巡检时间和频率
- **异常检测**: 自动识别异常情况并报警

### 2. 患者监护
- **生命体征监测**: 心率、呼吸率、血压等数据采集
- **跌倒检测**: 基于计算机视觉的实时跌倒检测
- **IV袋监控**: 输液袋液位检测和报警
- **拍照记录**: 自动拍摄患者状态照片

### 3. 环境感知
- **雷达避障**: 实时障碍物检测和路径调整
- **深度感知**: RealSense 深度相机提供三维环境信息
- **多传感器融合**: 整合多种传感器数据提高准确性

### 4. 人机交互
- **面部表情**: 丰富的表情动画增强交互体验
- **语音交互**: 支持语音提示和指令接收
- **远程控制**: 通过前端界面进行远程操作

### 5. 数据管理
- **巡检记录**: 完整的巡检历史和结果记录
- **报警管理**: 异常事件的记录和跟踪
- **患者档案**: 患者信息和医疗数据管理
- **地图管理**: 多楼层地图和导航点位管理

## 📊 应用场景

| 场景 | 功能描述 |
|------|----------|
| **病房巡检** | • 定时巡视病房，检查患者状态<br>• 自动记录患者生命体征数据<br>• 发现异常情况及时报警 |
| **夜间监护** | • 夜间不间断患者监护<br>• 跌倒事件实时检测和报警<br>• 减少护士夜间工作负担 |

>

### 启动服务

> [!note]
>
> 已支持一键启动脚本

```bash
bash run-all-terminals.sh
# or
.\run-all-terminals.bat
```

在 `boot_items.yaml` 可以自定义启动行为：

```yaml
items:
  # 后端服务
  - xiaobei-backend:
      scripts:
        - run
  
  # 前端服务
  - xiaobei-frontend:
      scripts:
        - run, 2s
  
  # 扩展服务
  - xiaobei-ext:
      scripts:
        - run_ms, 3s  # mediamtx 服务
        - run, 3s    # xiaobei-ext 服务
        - run_fall_detector: skip   # 跌倒监测服务

  # 机械臂服务
  - xiaobei-arm:
      status: skip
      scripts:
        - 1_run_ros   # 睿感机械臂 ros 驱动
        - 2_run_srv   # ros-uv 通信中间件
        - 3_run_fastapi   # 机械臂通用接口

  # 面部动画服务
  - xiaobei-face:
      status: skip
      scripts:
        - run
```
