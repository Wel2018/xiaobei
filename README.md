# Xiaobei 医院巡检机器人系统

## 📖 项目简介

Xiaobei 是一个智能化的医院巡检机器人系统，专为现代医疗机构设计，能够自主执行病房巡检、患者监护、生命体征采集等任务。该系统集成了先进的机器人技术、计算机视觉、传感器融合和人工智能算法，为医护人员提供高效、准确的辅助服务。

## 🏗️ 系统架构

### 整体架构
```
xiaobei/
├── xiaobei-backend/          # 后端服务 (FastAPI, 端口 8000)
├── xiaobei-frontend/         # 前端界面 (Vue.js + TypeScript)
├── xiaobei-ext/             # 设备服务 (摄像头、跌倒检测等, 端口 8001)
├── xiaobei-arm/             # 机械臂控制服务
├── xiaobei-face/            # 面部表情动画播放器
└── xiaobei-data/            # 数据存储 (地图、配置等)
```

### 核心组件

#### 1. 后端服务 (xiaobei-backend)
- **技术栈**: FastAPI, Python, SQLite
- **功能模块**:
  - 底盘控制与状态监控
  - 机械臂控制与管理
  - 地图管理与导航点位
  - 头部舵机控制
  - 巡检任务管理
  - 患者信息管理
  - 生命体征数据采集
  - 报警记录管理
  - 传感器数据集成

#### 2. 前端界面 (xiaobei-frontend)
- **技术栈**: Vue.js, TypeScript, Vite
- **功能模块**:
  - 实时监控面板
  - 地图可视化
  - 设备状态监控
  - 巡检任务管理
  - 患者信息展示
  - 报警记录查看
  - 系统设置管理

#### 3. 设备服务 (xiaobei-ext)
- **技术栈**: FastAPI, OpenCV, pyrealsense2
- **功能模块**:
  - RealSense D455 深度相机支持
  - USB 相机管理
  - 视频流传输 (WebSocket)
  - 跌倒检测算法
  - IV袋检测
  - 消毒灯控制

#### 4. 机械臂服务 (xiaobei-arm)
- **功能**: 睿感机械臂 ROS 驱动和 Socket 通信中间件

#### 5. 面部表情服务 (xiaobei-face)
- **技术栈**: PySide6, python-vlc
- **功能**: 机器人面部表情动画播放

## 🚀 核心功能

### 1. 智能巡检
- **自动路径规划**: 基于预设地图和导航点位的自主导航
- **多床位巡检**: 支持按病房、床位分组进行巡检
- **定时巡检**: 可配置巡检时间和频率
- **异常检测**: 自动识别异常情况并报警

### 2. 患者监护
- **生命体征监测**: 心率、呼吸率、血压等数据采集
- **跌倒检测**: 基于计算机视觉的实时跌倒检测
- **IV袋监控**: 输液袋液位检测和报警
- **拍照记录**: 自动拍摄患者状态照片

### 3. 环境感知
- **雷达避障**: 实时障碍物检测和路径调整
- **深度感知**: RealSense 深度相机提供三维环境信息
- **多传感器融合**: 整合多种传感器数据提高准确性

### 4. 人机交互
- **面部表情**: 丰富的表情动画增强交互体验
- **语音交互**: 支持语音提示和指令接收
- **远程控制**: 通过前端界面进行远程操作

### 5. 数据管理
- **巡检记录**: 完整的巡检历史和结果记录
- **报警管理**: 异常事件的记录和跟踪
- **患者档案**: 患者信息和医疗数据管理
- **地图管理**: 多楼层地图和导航点位管理

## 🔧 技术特性

### 高性能架构
- **异步处理**: 基于 FastAPI 的异步 Web 框架
- **实时通信**: WebSocket 支持实时视频流和数据传输
- **缓存机制**: 设备列表和数据缓存提高响应速度

### 模块化设计
- **微服务架构**: 各功能模块独立部署和运行
- **API 标准化**: RESTful API 设计，符合 OpenAPI 标准
- **插件化扩展**: 支持新功能模块的快速集成

### 智能化算法
- **计算机视觉**: YOLO 姿态估计用于跌倒检测
- **路径规划**: 基于地图的智能导航算法
- **数据分析**: 患者数据的统计分析和趋势预测

### 安全可靠
- **权限管理**: 用户访问控制和操作权限管理
- **数据加密**: 敏感数据传输和存储加密
- **故障恢复**: 系统异常时的自动恢复机制

## 📊 应用场景

### 1. 病房巡检
- 定时巡视病房，检查患者状态
- 自动记录患者生命体征数据
- 发现异常情况及时报警

### 2. 夜间监护
- 夜间不间断患者监护
- 跌倒事件实时检测和报警
- 减少护士夜间工作负担

### 3. 输液监控
- 实时监控输液袋液位
- 输液完成前预警提醒
- 防止输液事故发

### 4. 康复辅助
- 协助患者进行康复训练
- 记录康复进度和数据
- 提供个性化的康复指导

## 🛠️ 开发环境

### 系统要求
- **操作系统**: Linux/Windows/macOS
- **Python**: >= 3.11
- **Node.js**: >= 18.0
- **内存**: >= 8GB RAM
- **存储**: >= 50GB 可用空间

### 依赖安装
```bash
# 后端服务
cd xiaobei-backend
uv sync

# 前端服务
cd xiaobei-frontend
pnpm install

# 设备服务
cd xiaobei-ext
uv sync

# 面部表情服务
cd xiaobei-face
uv sync
```

### 启动服务
```bash
# 启动所有服务
./start-all.sh

# 或分别启动
# 后端服务
cd xiaobei-backend && uv run python main.py

# 前端服务
cd xiaobei-frontend && pnpm dev

# 设备服务
cd xiaobei-ext && uv run python main.py
```
